# Barbearia Vidigal — React + Vite

Projeto demonstrativo de portfólio.

## Rodar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Vercel
Envie para GitHub e importe o repositório na Vercel. O Vite usa `index.html` como entrada e a Vercel consegue detectar o projeto Vite automaticamente.

**Atenção:** avaliações, endereço, telefone, Instagram, WhatsApp e fotos são demonstrativos. Substitua pelos dados reais se for usar comercialmente.
